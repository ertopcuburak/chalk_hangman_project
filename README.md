# 🪶 Chalk Hangman

A simple Hangman game built with Flutter. It features Turkish word support and a chalkboard-themed UI.

## 🎮 Features

- 🇹🇷 Turkish word support  
- 🪶 Chalkboard-style design  
- 🎯 Random word generation  
- ❌ Hangman drawing progression on wrong guesses  
- 📱 Mobile-friendly Flutter app  

## 🚀 Installation

```bash
git clone https://github.com/username/chalk_hangman.git
cd chalk_hangman
flutter pub get
flutter run
